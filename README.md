# Students DB

Учебное консольное приложение на C++ для хранения и управления данными студентов.

Проект создан для практики объектно-ориентированного программирования, работы с коллекциями, файлами, проверкой пользовательского ввода и разделением программы на классы.

## Возможности

- добавление нового студента;
- удаление студента по ID;
- вывод списка всех студентов;
- сортировка студентов по ID, имени, дате рождения или GPA;
- сохранение данных в текстовый файл;
- загрузка данных из текстового файла;
- проверка формата даты рождения;
- проверка допустимого значения GPA;
- обработка некорректного ввода в консоли.

## Данные студента

Для каждого студента хранятся:

- уникальный ID;
- имя;
- дата рождения в формате `dd.mm.yyyy`;
- средний балл GPA от `0.1` до `4.0`.

## Структура проекта

```text
students-db/
├── Student.h
├── Student.cpp
├── StudentManager.h
├── StudentManager.cpp
├── main.cpp
├── students.txt
└── students db.sln
```

### `Student`

Класс представляет одного студента. Он хранит данные, предоставляет getters и setters, выводит информацию в консоль и проверяет корректность даты рождения и GPA.

### `StudentManager`

Класс управляет коллекцией студентов. Он отвечает за добавление, удаление, сортировку, вывод, сохранение и загрузку данных.

### `main.cpp`

Содержит консольное меню и обработку пользовательского ввода.

## Запуск проекта

1. Склонируйте репозиторий:

```bash
git clone https://github.com/sibcoww/students-db.git
```

2. Откройте файл решения:

```text
students db.sln
```

3. Запустите проект в Visual Studio через `Ctrl + F5`.

## Консольное меню

После запуска приложение предлагает выбрать действие:

```text
1. Add new student
2. Delete student
3. Print all students
4. Sort student by ...
5. Load from file
6. Save to file
0. Exit
```

## Хранение данных

Данные сохраняются в файл `students.txt` рядом с исполняемым файлом программы. При следующем запуске их можно загрузить через соответствующий пункт меню.

Пример данных:

```text
1 yermek 03.11.2004 3
2 Olzhas 28.10.1998 4
```
